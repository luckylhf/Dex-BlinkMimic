# 固定数据 Blink 配方（2026-11-07）

本轮从随机初始化训练 3500 次，采用 BlinkMimic `PRESET[main]` 并适配 Dex。其 SuperMimic 基线来自第三方重实现；上游 G1 的性能数据不能直接用于本项目。

实验已完成。本地结果包见[指标、8 段视频与曲线](../test/results/blink_recipe_fresh3500_20261107/README.md)（未随 Git 仓库提供）。本页集中说明数据、参数、显存适配与复现条件。

## 固定数据

| 项目 | 数量 |
|---|---:|
| BONES：已验收、非人工镜像 | 26,815 条 |
| LAFAN：原探索数据，保留 2 accepted / 75 review | 77 条 |
| 合计 | 26,892 条、6,006,647 帧、133,066 个一秒时间桶 |
| 排除的人工镜像源 | 8,738 条 |

`freeze_recipe_dataset.py` 复制已完成批次的验收清单和选用 NPZ，排除源文件名以 `_M` 结尾的条目，并按源 SHA-256、训练文件 SHA-256、统一四元数符号后的动作数组哈希去重。保留条目未发现这三类完全重复；相似录制和独立左右动作仍保留。

训练快照拥有独立文件副本。全程固定该快照，按上游均匀一秒时间桶先验结合回报/失败统计采样；不做 LAFAN/BONES 各半加权，也不动态接入新转换结果。

## 训练参数

配置文件：[dex_blink_recipe.json](../configs/dex_blink_recipe.json)。

| 参数 | 设置 |
|---|---|
| 环境 / 迭代 / 回放 | 4096 / 3500 / 1000 步 |
| 世界模型（WM） | 结构化，隐藏层 1024×3，窗口 8，每轮更新 5 次 |
| 策略想象长度 / WM 与策略 batch | 32 步 / 各 2048 |
| 优化器 / 基础学习率 | Muon/Adam 混合 / `4e-4` |
| 策略学习率调度 | 初始倍率 4；回报达到 0.75 或最迟第 1400 次触发，300 次内降至 1 |
| EMA / WM 镜像比例 | 0.995 / 0.5 |
| 接触奖励 / 参考接触 | 0.25 / 按动作标定足底高度 |
| 失败重置 / 探测重置份额 | 0.3 / 0.15 |

启用参考动作前馈、CUDA 图和评测引导重置；关闭额外 `root_feedback` / `root_reward`。Dex 模型、关节约定、PD 增益、动作缩放和域随机化配置沿用本项目适配。足踝原点接触阈值为 0.06 m，并通过碰撞几何检查。

### 镜像约束

Dex 腰 yaw 限位不对称。镜像样本只选当前/下一帧均在对称可达区间内的窗口，预留 0.005 rad；状态、动作、仿真上下文与连续性掩码使用同一索引。有效窗口不足半个 batch 时复用，完全没有时终止，实际计数写入 `mirror_diagnostics`。

模型保留原始的毫米级左右几何差异。镜像几何检查使用严格 FP32，训练仍采用融合旋转运算和混合精度。

## 16 GiB vGPU 适配

| 适配 | 实现与影响 |
|---|---|
| 全库紧凑参考 | `CompactMotionLib` 将全部 FP32 根部/关节状态和固定帧、时间桶索引常驻 GPU；按查询帧执行 FK。无分片轮换或 replay 清空 |
| CUDA 图内存复用 | 采集、世界模型和策略图顺序共用 PyTorch 内存池，探测图单独分配 |
| 反传重计算 | 无状态 MLP 使用非重入 checkpoint，减少 32 步想象期间保留的激活；按 FP32/BF16 对照输出与梯度 |
| critic 特征 | 按时间步构造同一份完整输入；完整 batch 的归一化、critic 前向、GAE 及更新批次保持不变 |
| Warp 临时数组 | RTX5880-Ada-16Q 不支持 Warp memory pool，进程内按 Data 预分配 scratch arena，保留初始化语义；与原分配路径单独比较仿真状态 |

上述适配保留网络规模和训练逻辑 batch。训练采用 `eprobe_async=0`，适用于与桌面共享 GPU 的环境；世界模型和策略 CUDA 图仍启用。显存和吞吐以完整配置的实际记录为准。

### 有界失败探测

上游一次为所有动作窗口分配仿真实例，本轮限制为 2048 个探测实例。第 1000 次后每 125 次轮换一批，覆盖记录写入 `probe_coverage.jsonl`；完整 checkpoint 保存游标与探测状态。

每次只扫描部分窗口，失败权重按该批次衰减 0.7。因此它与上游“一次全库扫描、每轮衰减”的调度不同；即使累计覆盖全库，也不代表最终模型完成了一次全库验收。

## 准备与运行

需具备冻结数据及训练环境，所有输出使用新目录。在项目根目录依次执行或核对：

1. 用 `freeze_recipe_dataset.py` 准备快照，保留去重结果和原质量标签；输入要求见 `--help`。
2. 用 `check_recipe_environment.py --dataset /path/to/frozen --build --report /path/to/new_preflight.json` 构建 `compact.pt` 并检查环境。检查包括镜像、足底几何、普通/紧凑参考的 goal、FK、接触、奖励与梯度一致性，以及仿真状态读回和有限数值。
3. 按 `run_recipe_smoke.py` 的参数完成小规模及全配置 CUDA 图短测，覆盖探测轮换、Muon、保存与恢复；保留显存、特征和梯度对照报告。
4. 检查通过后，从主 README 的命令启动新训练，保存 `args.json`、数据/代码/模型哈希、零更新模型、checkpoint 和资源日志。

这些脚本使用已安装训练依赖的 Python，并设置 `PYTHONPATH=src`。`run_recipe_fresh.py` 是本次实验的专用启动器：其中检查回执路径固定为 11 月 7 日实验目录；复现前需准备对应材料，不能把它当作任意数据目录的通用启动器。

## 评测与已完成结果

在零更新和最终模型上评测 GBTC、dance-boy、dance-girl，以及代表性 LAFAN 走跑动作。LAFAN 两条属于训练内；三个常用开发动作也不能称为盲测。终止采用 `jump_tracking_v2`，全局位置误差单独报告，训练端终止规则保持原配置。

本轮使用 11 月 7 日更新素材、既定 SuperMimic 预处理和独立 history，未覆盖[历史冻结三动作集](../data/evaluation/supermimic_12341_v1/README.md)。训练完成后，GBTC 和两条 LAFAN 播放到结尾，舞蹈仍有提前终止，全局漂移明显。详细指标及验证记录见本页开头的结果包；这些仿真结果不代表全部动作或真机验收。
